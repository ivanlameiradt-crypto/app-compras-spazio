- Só o **Boleto** foi provado ao vivo. PIX/Dinheiro/Tesouraria/Cartão podem quebrar depois do pedido criado.
- **Não existe "Lançar todas"** e não deve existir do jeito simples: o grupo `sischef-session` guarda só um run pendente,
  então vários disparos seguidos cancelariam uns aos outros. Se vier, tem que ser uma fila (um run que lança várias).
- **Minutos do GitHub (repo privado):** o reaper roda a cada 30 min, mais TV, leitura e agora 3 sincronizações/dia
  (~2–3 min cada). Vale conferir o consumo em Settings → Billing antes do fim do mês.
