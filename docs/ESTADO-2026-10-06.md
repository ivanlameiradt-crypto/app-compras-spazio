## Fluxo combinado (06/10): o Ivan confirma, o robô lança
O Ivan analisa e confirma as notas no app; o robô lança no Sischef. **Um robô por vez:** o GitHub guarda só 1 run pendente por
grupo `sischef-session` e cancela o anterior, então vários disparos seguidos perderiam lançamentos e deixariam notas presas em
"Lançando…". Por isso (já feito): o app bloqueia o Lançar das outras notas enquanto uma está lançando e a Edge Function `lancar-nfe`
recusa com 409 ("o robô está lançando outra nota"). Cada nota leva uns 3 minutos. Fila de verdade (confirmar várias e o robô lançar
em sequência num run só) fica para depois.
